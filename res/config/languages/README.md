# res/config/languages — data-driven lexer definitions

Editable keyword/property definitions for the Scintilla container lexer (SLADE's
pattern). One file per language: ZScript, DECORATE, ACS, MAPINFO/ZMAPINFO, GLDEFS,
SNDINFO, ANIMDEFS, TEXTURES, LANGUAGE, etc. Keeping these as **data** lets keyword
lists track GZDoom releases without recompiling. Files land in Phase 1.
